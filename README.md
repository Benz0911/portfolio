# Benz M. De Guzman — Portfolio

Personal portfolio: software engineer with 10 years of experience building, maintaining and modernizing web applications and business systems.

A static site with no build step: `index.html`, plus `assets/css`, `assets/js` and `assets/img`.

- **Pages:** Home, Work, About and Contact. One shows at a time, chosen by the URL hash (`#work`, `#about`, …). Without JavaScript they all show, one after another.
- **Screenshots:** colleagues' and clients' names are blacked out. Client work under NDA has no screenshots.
- **Fonts:** Inter and Bebas Neue, from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5502
```

Then visit http://localhost:5502.
